# Life by Design

A calm, interactive workshop for noticing what gives you energy, imagining multiple futures, and taking one small step toward a fuller life.

Inspired by the high-level frameworks in *Designing Your Life* by Bill Burnett and Dave Evans. This is an independent educational project and is not affiliated with the authors or publisher.

## Stack

- Next.js App Router
- TypeScript
- React
- Plain CSS design tokens and components
- Browser-only persistence with `localStorage`

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Experience

- The five canonical designer mindsets from the book
- A four-part Health, Work, Play, and Love dashboard
- Lifeview, Workview, and coherence reflections
- An interactive energy and engagement log
- Three editable Odyssey paths
- An eight-question guided reflection
- Responsive, accessible layout with reduced-motion support

See [`docs/design-system.md`](docs/design-system.md) for the visual language and Claude Design prompts.

See [`docs/content-overview.md`](docs/content-overview.md) for the complete experience outline and eight reflection questions.
